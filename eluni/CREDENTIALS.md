## Команды

```powershell
npx prisma db push       # синхронизировать схему (есть поле userId в Complaint)
npx prisma generate      # перегенерировать Prisma Client
npm run seed             # заполнить тестовыми данными
npm run dev              # запустить Next.js
npm run bot              # запустить Telegram-бота (отдельный процесс)
```
